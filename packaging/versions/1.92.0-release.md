# Boost 1.92.0 for macOS

Boost 1.92.0 was released on August 12, 2026. This package uses C++20 and
targets macOS 10.15 or newer with a universal arm64 and x86_64 static binary.

The complete Boost header inventory is packaged. The compiled set includes
Context, Nowide, JSON, Serialization, URL, Log, Container, Timer, TypeErasure,
the portable Stacktrace backend, Cobalt, and Charconv alongside the established
date/time, filesystem, graph, locale, random, and threading libraries.

Release-specific deterministic tests cover Boost.Container `hub`,
Boost.Decimal `decompose`, Boost.Lockfree `bounded_ticket_queue`, and the fixed
Boost.System `unwrap_and_invoke` void-return path. Network-dependent behavior
is intentionally excluded from the runtime suite.

Upstream release: https://www.boost.org/releases/1.92.0/
